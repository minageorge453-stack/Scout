# كشافة كنائس زايد · النظام الداخلي

نظام إداري للمجموعة الكشفية لكنائس زايد. يحتوي على:

- **هوية المجموعة** — الرؤية، الرسالة، الأركان الستة
- **القطاعات الثلاثة** — متقدم · مبتدئ · أشبال
- **المنهج السنوي** — ٣ سنوات × ٦ محاور × ٣ قطاعات
- **خطط المواسم** — موسم ٢٠٢٦ والأرشيف
- **البروتوكولات** — القبول، الزي، المخيمات الخارجية، التأديب
- **القادة** — التوزيعات والمسؤوليات

## التشغيل

كل الملفات HTML/CSS/JS عادية. افتح `index.html` في المتصفح للدخول.
